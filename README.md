# Перекрёсток · «Орёл и решка» 🪙

Мини-игра для мобильного WebView в фирменном стиле X5 Group / «Перекрёсток».
Чистый HTML/CSS/JS, без сборки и зависимостей — просто открыть `index.html`.

## 🎮 Механика

1. Тап по монете → 3D-подброс с вибро-фидбеком (ASMR-паттерны через Vibration API).
2. **Орёл** (лицевая сторона с логотипом «Перекрёстка») → **+1 очко**.
3. **Решка** → **−1 балл лояльности**.
4. Каждые **10 очков** (орлов) — игроку начисляется **пачка чипсов** (лутбокс).
5. Лутбокс открывается за **100 баллов лояльности** → внутри промокод, который можно скопировать в буфер обмена одним тапом.
6. Когда баллы лояльности доходят до **0** — для теста они автоматически пополняются до **100** (см. `STARTING_LOYALTY` в `script.js`, легко заменить на реальный запрос к API лояльности).
7. Прогресс, очки и баллы сохраняются в `localStorage`, чтобы не сбрасывались при перезапуске WebView.

## ⚠️ Важно: кэш на телефоне / GitHub Pages

Мобильные браузеры (особенно в WebView) агрессивно кэшируют `style.css` и `script.js`.
**Если после обновления файлов что-то выглядит "как в старой версии" — в 95% случаев это кэш, а не баг в коде.**

### Как быстро проверить, что телефон видит именно новую версию

В самом низу экрана игры есть маленькая зелёная плашка **`build v4`** (рядом с надписью
"Дизайн — в фирменной айдентике X5 Group · демо"). Число в этой плашке = номер версии из `index.html`.

1. Открой сайт на телефоне.
2. Посмотри на плашку внизу экрана.
3. Если там написано `build v4` (или больше) — ты точно смотришь на актуальный код, и любые баги надо
   разбирать по существу.
4. Если там `build v3` / `build v2` / плашки нет вообще — значит, зафиксировался старый кэш, и надо его сбросить
   (см. ниже), либо на GitHub всё ещё лежит старая версия файлов.

### Как сбросить кэш на телефоне

- **Chrome / Android**: меню (три точки) → «История» → «Очистить историю» → отметь «Файлы cookie» и
  «Кэш изображений и файлов» → «Удалить данные». Либо проще: открой сайт в **вкладке инкогнито** —
  она никогда не берёт файлы из кэша.
- **Samsung Internet**: Настройки → Конфиденциальность → «Удалить данные браузера» → отметь кэш.
- **Safari / iOS**: Настройки телефона → Safari → «Очистить историю и данные».

### Как правильно деплоить обновления самому

В `index.html` подключение файлов сделано с версией в конце пути:
```html
<link rel="stylesheet" href="style.css?v=4">
<script src="script.js?v=4"></script>
```
**При каждом следующем обновлении `style.css` или `script.js` на GitHub Pages увеличивай число
`v=4` → `v=5` → `v=6`...** и заодно обнови текст плашки `build v4` → `build v5` в `index.html`
(ищи `id="buildTag"`). Так ты всегда будешь видеть на экране, какая версия реально загрузилась,
без гадания.

## 🖼 Как подключить логотип «Перекрёстка»

1. Положи файл лого в `assets/logo-orel.png` (рекомендуется: **квадратный PNG, прозрачный фон, ≥ 512×512px**).
2. Больше ничего делать не нужно — `index.html` уже ссылается на этот путь:
   ```html
   <img class="coin__logo" id="logoImg" src="assets/logo-orel.png" ...>
   ```
3. Если файла не будет — сработает `onerror` и вместо картинки покажется красивая текстовая заглушка «✕5» на мятном фоне (игра не сломается).

### Если пушишь через GitHub / GitHub Pages
- Просто закинь всю папку `perekrestok-coin-game` в репозиторий как есть, положив логотип в `assets/logo-orel.png`.
- Включи GitHub Pages (Settings → Pages → Branch: main → / (root) либо /docs).
- Открывай `https://<username>.github.io/<repo>/perekrestok-coin-game/` в WebView.
- Пути в проекте **относительные**, поэтому работает из любой подпапки.

## 🥡 «Пачка чипсов» — арт (опционально)

Сейчас пачка отрисована эмодзи (`🥡`) — это специально, чтобы игра выглядела законченной без единого внешнего файла.
Если хочешь заменить на свою иллюстрацию:

1. Положи PNG в `assets/chips-pack.png`.
2. В `index.html` замени:
   ```html
   <span class="lootbox__icon">🥡</span>
   ...
   <div class="chips-box__body">🥡</div>
   ```
   на:
   ```html
   <img class="lootbox__icon" src="assets/chips-pack.png" alt="">
   ...
   <img class="chips-box__body" src="assets/chips-pack.png" alt="">
   ```
3. Подгони размеры в `style.css` (`.lootbox__icon`, `.chips-box__body`) при необходимости.

## 📳 Вибрация (ASMR-эффект)

Используется стандартный `navigator.vibrate()`. В `script.js` вынесены готовые паттерны:

| Событие                         | Паттерн                              |
|----------------------------------|---------------------------------------|
| Тап по монете                    | короткий тик (12мс)                   |
| Подброс / вращение монеты        | серия быстрых микро-тиков ("прокатка")|
| Приземление монеты               | средний тик (35мс)                     |
| Победа (орёл)                    | лёгкая радостная дробь                 |
| Проигрыш (решка)                 | один резкий буст                       |
| Получена пачка чипсов             | праздничная дробь                       |
| Открытие лутбокса                 | нарастающая серия + финальный акцент   |
| Тест-пополнение баллов до 100     | двойной мягкий пульс                    |
| Копирование промокода             | микро-тик                               |

**Важно:** Vibration API работает только в контексте **пользовательского жеста** (тап) и почти везде в Android WebView, но **не поддерживается в iOS Safari/WKWebView** (ограничение Apple) — на iOS вибрация просто тихо не сработает, игра при этом не ломается (используется `try/catch`).
Если оборачиваешь в нативное приложение (Capacitor/Cordova/React Native WebView) и хочешь полноценный тактильный отклик на iOS — замени вызовы `vibrate()` на нативный мост (`Haptics.impact(...)`).

## 🎨 Дизайн

- Палитра взята из актуальной айдентики «Перекрёстка» / брендбука X5 Group:
  тёмно-зелёный `#0F5A05`, мятный `#EAFBDC`, тёплый крем `#FFF6EA`, золото `#FFC94A` (акцент для баллов/лутбокса).
- Декоративная сетка на фоне — отсылка к брендовой идее «пересечения» (крестообразные плашки).
- 3D-монета на чистом CSS (`transform-style: preserve-3d`), без библиотек.
- Конфетти и частицы — на `<canvas>`, лёгкие, без внешних зависимостей.
- Шрифт: `Manrope` (Google Fonts) — геометричный, близкий по духу к ритейл-айдентике. Если нужна полностью офлайн-версия без интернета — скачай `Manrope` локально и подмени `<link>` в `index.html` на `@font-face`.

```js
const PACK_COST = 100;         // цена открытия лутбокса в баллах лояльности
const HEADS_PER_PACK = 10;     // сколько орлов нужно для новой пачки чипсов
const STARTING_LOYALTY = 100;  // тестовое пополнение при 0 баллов
```

## 📱 Портретная ориентация

- Уже стоит `lock('portrait')` через Screen Orientation API (работает, если WebView в fullscreen-режиме).
- На случай, если поворот блокировать не получилось — есть экран-заглушка «переверни телефон» при `orientation: landscape`.

## 🔌 Интеграция с реальным лутбоксом/промокодами

Сейчас промокод генерируется случайно на клиенте (`generatePromoCode()` в `script.js`) — это удобно для демо/теста.
Для продакшена замени эту функцию на `fetch()`-запрос к своему backend/CRM лояльности, который отдаёт реальный уникальный промокод и списывает баллы на сервере (чтобы избежать читерства через локальный localStorage).
